# test_v01_improvements.py 代码逻辑

## 职责

验证城市别名、固定 ERA5 历史聚合、分块缓存、灾害摘要、预报聚合和单位边界等产品改进。

## 输入与输出

- 输入：合成日表、城市种子行、pytest 隔离目录和模拟接口响应。
- 输出：无文件产物；通过断言确认数据源与聚合契约。

## 函数与类
| 名称 | 职责 | 关键输入/输出 |
| --- | --- | --- |
| `test_historical_*` | 验证月度聚合、直接湿度、固定模型与风速单位 | 合成历史表 / 指标与请求参数 |
| `test_history_*cache*` | 验证五年分块和实际日期覆盖 | 缓存表 / 网络调用范围 |
| `test_earthquake_*` | 验证震级和距离分档 | 合成事件 / 摘要 |
| `test_forecast_*` | 验证预报阈值、场景分和公英制 | 合成预报 / `ForecastSummary` |
| 其他测试 | 验证别名、极光和台风路径摘要 | 种子与合成记录 / 断言 |

## 数据流与主要步骤
1. 构造最小但语义完整的历史/预报/灾害表。
2. 断言历史请求固定 `era5`、直接读取湿度，并以米/秒解释风速阈值。
3. 用文件名宣称完整但实际缺尾日的缓存验证完整性检查，只补取真实缺口。
4. 验证各评分和展示摘要在单位、距离与时间尺度上保持一致。

## 依赖、配置与运行方式

使用 pytest、pandas 和项目公开函数；网络请求全部模拟。

## 假设、边界与注意事项

pytest 创建的隔离目录只在测试期存在，不作为项目产物保留。
