# test_scoring.py 代码逻辑

## 职责

验证评分、城市筛选、数据加载和地图坐标转换的关键行为。

## 输入与输出

- 输入：构造的城市数据框、偏好与指标。
- 输出：对筛选结果和评分边界的断言。

## 数据流与主要步骤

1. 构造代表性城市和跨国家城市样本。
2. 调用筛选与评分函数。
3. 验证国家筛选只保留选定国家/地区，国家与城市组合后只保留两项共同匹配的城市，且其他既有筛选行为不变。

## 依赖、配置与运行方式

- 使用 pytest 与 pandas；运行 `pytest tests/test_scoring.py`。

## 假设、边界与注意事项

- 测试只验证本地数据处理，不访问外部数据服务。
