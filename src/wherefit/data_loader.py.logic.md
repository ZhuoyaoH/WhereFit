# data_loader.py 代码逻辑

## 职责

加载并验证城市种子表、NASA POWER 月度/年度气候基线与 ACAG 城市年度 PM2.5 表，将它们转换为位置和气候指标。

## 核心规则

- 拒绝重复城市、非法坐标和越界等级。
- 合并月度和年度 POWER 表，要求每城恰好覆盖 0—12 共 13 个周期，且年份、温湿度、阈值日数和缺失率合理。
- 校验 PM2.5 城市—年份唯一性、浓度范围、格点数、版本和空间方法，聚合十年均值、标准差与线性趋势。
- 运行时优先读取固定 POWER 聚合值；日均相对湿度为直接数据，体感温度和雪日代理明确列入 `estimated_fields`。
- 仅当版本化气候文件或城市周期缺失时，月份 1—12 才应用人工季节因子；南半球会反转季节相位，月份 0 聚合十二个月并明确标记回退。
- 全年日数是年度总量，并用 `period_months=12` 告知评分层换算为月均率。
- 长期 PM2.5 独立使用 ACAG 融合数据；气候或空气质量文件缺失时，各自回退且不影响另一数据组的来源标记。
- 城市内部标识始终使用稳定英文名；显示层通过统一函数返回中文或英文。中文中拉萨保持“拉萨”，香港和澳门完整显示为“香港特别行政区”“澳门特别行政区”，同时保留这些全称作为可解析的输入别名。
