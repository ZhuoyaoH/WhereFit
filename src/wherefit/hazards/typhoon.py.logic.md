# typhoon.py 代码逻辑

## 职责

按城市坐标选择 NOAA IBTrACS v04r01 官方海盆子集，缓存并汇总 2000 年以来城市周边热带气旋路径。

## 输入与输出

- 输入：`Location`、缓存目录、起始年份和刷新选项。
- 输出：100/200/500km 内的唯一风暴数量、最近距离、最强/最近风暴和地图路径点。

## 核心流程

1. 把经度归一化到 -180 至 180 度，根据城市半球、纬度和经度选择 NA、EP、WP、NI、SI 或 SP；欧洲经度范围内的北纬 35 度以上城市使用北大西洋子集，海盆边界附近可选择两个子集。
2. 分海盆下载官方 CSV 并写入确定性缓存文件，读取后过滤年份和无效坐标。
3. 多海盆结果按 `SID` 与 `ISO_TIME` 去重，避免边界记录重复。
4. 先计算所有路径点到城市的球面距离，再按每个 `SID` 的最小距离统计唯一风暴。
5. 下载或解析失败时返回显式 `failed` 状态，不回退到其他地区的海盆数据。

## 边界

- 路径接近次数是历史目录统计，不是受灾次数、概率或安全评级。
- 坐标规则是面向城市的近似海盆路由；海盆边缘并不替代 NOAA 的风暴归属字段。
