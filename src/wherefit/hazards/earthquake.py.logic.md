# earthquake.py 代码逻辑

## 职责

按城市中心、半径、震级和时间范围查询 USGS 地震目录，生成距离分档、震级分档和可视化事件样本。

## 输入与输出

- 输入：`Location`、缓存目录、日期范围、半径、最小震级和刷新选项。
- 输出：`EarthquakeSummary`；完整成功的规范化事件表写入 CSV 缓存。

## 函数与类
| 名称 | 职责 | 关键输入/输出 |
| --- | --- | --- |
| `get_earthquake_summary` | 读取缓存或按时间块查询并汇总 | 城市与查询参数 / `EarthquakeSummary` |
| `_fetch_chunk_features` | 在单个五年块内按 `limit/offset` 稳定分页 | 日期块 / GeoJSON feature 列表 |
| `_features_to_rows` | 规范化事件 ID、时间、震级、坐标和深度 | feature 列表 / 表格行 |
| `_earthquake_date_chunks` | 生成无重叠的日历年块 | 日期范围 / 日期块列表 |
| `summarize_earthquakes` | 计算震级、距离和最近事件摘要 | 事件表 / `EarthquakeSummary` |

## 数据流与主要步骤
1. 缓存键包含城市、完整日期、半径和实际最小震级。
2. 缓存缺失时按五年拆分 2000 年以来的范围，每块结束时间覆盖结束日 23:59:59.999，避免漏掉最后一天并避免单次查询触及 USGS 20,000 条上限。
3. 每个时间块以 `time-asc` 固定排序，并用 1 起始的 offset 分页；事件按官方 ID 去重。
4. 全部时间块成功才写缓存；部分失败时返回 `partial` 并只展示可用记录，不把不完整结果固化。
5. 最终统计 100/200/500 km 内累计事件及 M4/M5/M6 分档，明确它们不是年发生率或安全概率。

## 依赖、配置与运行方式

使用 requests 调用 `USGS_EARTHQUAKE_URL`，pandas 规范化事件；由灾害页面按需触发。

## 假设、边界与注意事项

- 500 km 圆形检索是城市中心附近的目录摘要，不等同于行政区地震危险性。
- 页面地图最多展示按震级和时间排序的 350 条事件，统计值仍基于完整已取回事件表。
