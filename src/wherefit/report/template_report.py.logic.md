# template_report.py 代码逻辑

## 职责

把评估结果渲染为文本报告，包含你的偏好匹配分、分项情况、长期 PM2.5 输入与年份、数据状态和限制说明。城市卡片只给出分数及其主要原因；“不是概率或安全评级”的使用边界集中在方法说明中，避免在每张卡片重复显示。

## 语义约束

报告使用“本次比较中的匹配度”和“糟糕天气指数”，不把分数写成安全性、健康结论或灾害概率。

月份在英文报告中使用标准日历月份名称（例如 `August`），全年使用 `full-year`，避免把月份误写成时长。

中文报告使用统一城市显示名：拉萨保持中文，香港和澳门完整写为“香港特别行政区”“澳门特别行政区”。
