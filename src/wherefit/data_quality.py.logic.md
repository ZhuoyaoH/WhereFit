# data_quality.py 代码逻辑

## 职责

把每个城市的评分输入转换为可阅读的数据来源、时间范围、数据覆盖时间、备用值状态和是否用于排序的记录。

## 数据流

`CityResult` → 气候/湿度/ACAG 长期空气质量（含独立年份与空间方法）/灾害记录 → 可选预报与近期空气质量 → `DataQualityRecord` 列表。

## 边界

灾害记录固定标记为不影响主评分；ACAG 说明为融合多类资料得出的城市周边估算，而非单个监测站；POWER 的直接湿度不标记为估算，气候记录单独说明体感温度为计算值、可能下雪日为推算值；按需 ERA5 缺少直接湿度时才显示湿度估算；缺失城市才显示备用参考值，避免把“数据来源”误解为准确率。
