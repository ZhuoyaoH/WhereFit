# charts.py 代码逻辑

## 职责

生成排名、分项和城市对比图表。

## 语义约束

图轴和图例区分气候舒适、糟糕天气更少、短期预报与偏好匹配，避免用“安全”或概率词汇替代评分含义。雷达图将 `100 - 高温风险`、`100 - 强降水风险` 直白标为“高温较少”“强降雨较少”；柱状图的“糟糕天气更少”也使用 `100 - 糟糕天气指数`。这些图中数值越高只表示本次比较更符合偏好；原始指数仍在排名表和城市卡片中独立展示。

排名柱状图使用 Okabe–Ito 色盲友好系列的蓝 `#0072B2`、蓝绿 `#009E73`、紫红 `#CC79A7`，按图例顺序对应偏好匹配、气候舒适和糟糕天气更少。颜色只辅助类别区分，不承载唯一信息。城市气候特点雷达图使用半透明浅紫 `rgba(196, 181, 253, 0.50)` 填色、深紫 `#7C3AED` 轮廓和 `#6D28D9` 端点，数据维度和数值不随配色改变。

图例和横轴复用统一城市显示名；中文模式中香港、澳门使用完整“特别行政区”名称。
