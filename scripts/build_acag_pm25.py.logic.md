# build_acag_pm25.py 代码逻辑

## 职责

从 ACAG SatPM2.5 V6.GL.03 官方公开 S3 下载固定年份的全球年度栅格，提取 WhereFit 城市周边 PM2.5 并生成可审计的小型数据表和校验清单。

## 输入与输出

- 输入：`data/city_seed.csv`、年份范围、0.1° ACAG 年度 NetCDF 文件。
- 输出：城市—年份 PM2.5 CSV、包含源文件 URL/大小/SHA-256/许可/方法的 JSON manifest。

## 函数与类

| 名称 | 职责 | 关键输入/输出 |
| --- | --- | --- |
| `parse_years` | 解析年份参数 | 文本 / 年份元组 |
| `grid_window` | 将城市坐标转换为裁剪后的网格窗口 | 经纬度 / 起点与大小 |
| `download_annual_file` | 流式下载一个官方年度文件，并对瞬时网络错误执行有限重试 | 年份 / 文件路径与 URL |
| `extract_city_pm25` | 用 `h5dump` 提取 3×3 窗口并计算有限值均值 | 文件、坐标 / 均值与格点数 |
| `build_city_records` | 构建全部城市—年份记录 | 种子表、年份 / 数据表与来源清单 |
| `write_outputs` | 写入 CSV 和可追溯 manifest | 记录与来源 / 两个持久化产物 |
| `remove_downloads` | 删除本轮使用的一次性全球源文件 | 明确文件路径 / 无 |

## 数据流与主要步骤

1. 校验种子表和年份参数。
2. 逐年下载约 5.2 MB 的 0.1° 全球年度文件并计算 SHA-256。
3. 将城市坐标映射到 ACAG 固定网格，读取中心格点周边 3×3 窗口。
4. 忽略非有限/负值后计算年度均值，记录有效格点数。
5. 写入 77 城市十年长表和完整来源 manifest；默认删除全球源文件。

## 依赖、配置与运行方式

运行 `WhereFit/.conda-env/bin/python scripts/build_acag_pm25.py`。运行时依赖项目现有 pandas/requests，以及系统 HDF5 工具中的 `h5dump`；主应用不需要 HDF5/NetCDF 依赖。

## 假设、边界与注意事项

- V6.GL.03 是卫星、模拟和监测融合估计，不是纯地面站观测。
- 3×3 0.1° 窗口表示城市中心附近的网格均值，不是行政区人口加权暴露。
